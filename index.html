Installing

Four steps, once.

  1. Download the APK using the button above.
  2. Open it. Android will ask whether to allow installs from your browser — this is normal for an app that does not come from the Play Store. Allow it, then install.
  3. Grant the permissions the setup screen asks for. Each one is explained there; the app cannot listen or paste without them.
  4. Add a Gemini API key. Get a free one at aistudio.google.com/apikey and paste it into Settings. Transcription runs on your own key, so nothing goes through anyone else's server.
If you already have an older build installed — one you got before this page existed — uninstall it first. Android refuses to replace an app when the new copy was signed with a different key. This is a one-time step; every version from here on updates normally.

Where your words go

Straight to Google, on your own key.

Audio is sent to Google Gemini for transcription using the API key you provide, and is not stored by NextVoice. Your key is kept encrypted on your device. Signing in with Google is optional and only backs your settings up to a private document that only you can read.
